Decree 53 Routing Flow (per GQL request):
1. Client sends POST /api/gql to FastAPI frontend
2. gqlproxy_localized classifies query keywords
3. Forwards request to GQL_PROXY (gql_ug / Apollo)
4. DataRouter.process() called after upstream responds
5. Every request → writes ip_logs to Local_DB (MySQL)
6. user_profile mutation → additionally writes user_profile_audit
7. app_metadata / image_cache → forwarded only, no local write
8. Response headers: X-Data-Category and X-Decree53-Routed: local | global
